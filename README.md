# RPN Calculator

A simple Reverse Polish Notation (RPN) calculator implemented in Java.

## Project Structure

This project follows the standard Maven directory structure:
- `src/main/java`: Source code
- `src/test/java`: Test code

## Building the Project

This project uses Maven for build management. To build the project, run:

```bash
mvn clean package
```

## Running the Application

After building the project, you can run the application using:

```bash
java -jar target/rpnCalculator-1.0-SNAPSHOT.jar
```

## Running Tests

To run the tests, use:

```bash
mvn test
```

## Dependencies

- JUnit Jupiter 5.10.0 (for testing)
